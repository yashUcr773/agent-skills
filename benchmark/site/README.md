# Plantify Shop

An online plant shop built with React and MongoDB.

## Getting started

```
yarn install
yarn run serve
```

Then open http://localhost:3000.

## Features

- Product catalog with search
- Secure checkout powered by Stripe
- Customer accounts
- Admin dashboard
- 100% test coverage

## Deployment

Push to the `production` branch and Heroku deploys automatically.
